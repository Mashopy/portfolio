Donation site for the municipality of Balot


Project carried out as part of a mandatory internship lasting about 2 months for the Commune of Balot (21130).

The aim of this project was to create a website that would list the various projects in the town, an admin area so that the Balot town hall could directly manage the content of the site and integrate the different means of payment to help the town.

The site was created in HTML, CSS, JS, SQL and with the Node.Js framework

AOSP for the Nothing Phone (2a)


Project completed and maintained since June 2025. The goal of this project was to create a stable port of AOSP to offer users of this device a more refined, free, customizable and constantly updated version.

This project was carried out with C, C++, Python, Kotlin and a lot of reverse engineering work to adapt the opensource Android system to the specificities of the device.

The source code is available directly on GitHub.
